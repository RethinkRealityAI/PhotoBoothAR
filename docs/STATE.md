## Decisions
- DECISION (2026-07-29, Wave 7): the manager console's live feed is a POLL through `manager-api`, not `subscribeToPosts`. The console holds only the anon key (the body token is the credential), and Realtime applies RLS for `anon`, whose sole posts policy is `posts_public_read` = `approved and not hidden` — so a realtime channel would stream every post EXCEPT the unapproved ones, i.e. exactly the pre-moderation queue it exists to watch. A true realtime path needs an edge-fn/RLS change (see `## Open items`). Rationale is written into `src/lib/managerQueue.ts`'s docblock.
- DECISION (2026-07-25): `admin-api` deploys WITH this branch, never ahead of it. The four AI edge fns were deployed early because their improvements need no client change; admin-api's paging only pays off with the new client, and shipping it early would cap the live UI's user list at 100 where it expects 1000. An edge fn whose benefit REQUIRES its client ships with that client.
- DECISION (2026-07-25): a REQUIRED gap blocks every confirm press; a QUALITY gap (a real but vague brief) is asked ONCE and then the host is believed. Asking twice is arguing, not helping — and a host who wants "a gold frame" is allowed to have one.
